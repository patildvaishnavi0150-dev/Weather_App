# 🌦️ Weather App

A simple and responsive Weather Application built using HTML, CSS, and JavaScript. This app provides real-time weather information for any city using the OpenWeather API.

---

##  Features

-  Search weather by city name
-  Displays temperature, humidity, and wind speed
-  Dynamic weather icons
-  Fully responsive design
-  Real-time weather updates
-  Error handling for invalid city names

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript
